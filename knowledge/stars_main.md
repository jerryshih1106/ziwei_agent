# 天同

命宮持天同星者，面貌豐圓，性情穩定，懂生活享受，缺乏耐性，喜學習但無恆心，博而不精。命宮持天同太陰者，性急心慈，擅分析策劃，異性緣佳，自尊心強。命宮持天同巨門者，外務強，待人圓融，感情複雜，重享樂金錢。命宮持天同天梁者，喜戶外交遊廣，愛宗教活動，擅人際關係。天同化祿主解厄福氣好，易懶散。化權能激勵幹勁。化忌損人緣，易錯失機會。
